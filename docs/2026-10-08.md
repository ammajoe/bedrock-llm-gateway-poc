## 내린 결정: Docker 런타임으로 OrbStack 선택 (Docker Desktop 대신)
- **리소스 사용량**: kind는 노드를 Docker 컨테이너로 띄우고, 그 위에 LiteLLM + PostgreSQL + Prometheus/Grafana까지 올릴 예정이라 메모리·CPU가 빠듯하다. OrbStack은 유휴 시 메모리/배터리 소모가 Docker Desktop보다 적다.
- **기동 속도**: 몇 초 만에 엔진이 올라와 클러스터를 자주 만들고 지우는 실습에 유리하다.
- **호환성**: Docker CLI·Compose와 그대로 호환되고 `docker context`만 `orbstack`으로 바뀌므로 kind/Helm 워크플로우에 차이가 없다.
- **라이선스**: 개인 비상업 용도는 무료. (Docker Desktop도 개인 용도는 무료지만, 대기업 상업 용도는 유료 구독이 필요하다는 점은 참고.)
- **트레이드오프**: macOS 전용이고 Docker Desktop만큼 업계 표준은 아니다. 다만 이 프로젝트는 런타임에 의존하지 않고 운영 전환 시 EKS로 가므로 영향이 없다.
